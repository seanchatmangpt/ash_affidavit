## What this package is

Elixir/Ash wrapper over a Rust WASM engine (`affidavit.wasm`,
`wasm32-wasip1`, run via `wasmex`). The engine builds and checks receipts
over operation events, mines process models, checks signing inputs, and
certifies external AuthZEN / SPIFFE evidence.

**An "affidavit" here is a sealed receipt over operation events, not a signed
statement.** `AshAffidavit.call/2` dispatches to the engine's op registry
(`priv/affidavit/capability-registry.json`):

- `commit` — hash a payload into a `commitment` (pre-actuation binding).
- `assemble` — fold events into a receipt: returns `receipt` +
  `content_address` + `chain_hash` (integrity sealing).
- `verify` — re-check a receipt: `accepted`, `profile`, `outcomes`,
  `reason`, `content_address` (replay/verification).
- `mine` / `conform` — process mining and conformance checking over receipts.
- `verify_signature_input` — checks a signing input hex for an envelope
  (provenance-style check; the caller supplies the expected value).
- `certify_authzen_evidence` / `certify_spiffe_evidence` — evidence-only,
  authority NONE.

The package's own law: **grants no execution authority**. `{:ok, ...}` is the
engine's computation over exactly the request; the package refuses any engine
response claiming authority above NONE (`:authority_escalation`). Outcomes
kept distinct: `{:ok | :refused | :trap | :unsupported, ...}`.
