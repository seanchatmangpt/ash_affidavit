# Documentation

Documentation for `ash_affidavit`, in two trees:

- `documentation/` — the pages published in the hex docs (`mix.exs`
  `extras`): tutorials (`documentation/tutorials/getting-started.md`), topics
  (`documentation/topics/outcomes.md`) and the DSL reference
  (`documentation/dsls/DSL-AshAffidavit.Resource.md`).
- `docs/diataxis/` — the Diataxis-organized guide set, indexed by
  [docs/diataxis/README.md](../docs/diataxis/README.md): tutorials, how-to
  guides, reference and explanation; the signing-surface how-to lives at
  [docs/diataxis/how-to/signature-envelope.md](../docs/diataxis/how-to/signature-envelope.md).

Historical planning documents live under `docs/archive/` (moved from
`docs/sjira/`).
