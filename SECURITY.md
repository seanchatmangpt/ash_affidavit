# Security Policy

## Reporting

Report a suspected vulnerability privately through GitHub security advisories on
https://github.com/seanchatmangpt/ash_affidavit, or by email to xpointsh@gmail.com. Do not open a
public issue for it.

## Scope

- The engine bytes are admitted by SHA-256 pin, import surface and required exports before any
  instance exists. A bypass of that admission is in scope.
- This package grants no execution authority. A response that is read as an authorization is a
  usage error, not a vulnerability in the engine.
