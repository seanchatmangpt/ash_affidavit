# CHANGELOG

## 26.9.30

Initial release.

- `AshAffidavit.call/2`, `capabilities/1`, `abi_version/0`, `ops/0`, `registry/0` over the affidavit
  WASM engine (ABI 1, nine ops: `capabilities`, `commit`, `assemble`, `verify`, `mine`, `conform`,
  `verify_signature_input`, `certify_authzen_evidence`, `certify_spiffe_evidence`).
- Vendored engine `priv/affidavit/affidavit.wasm` (284650 bytes, sha256
  `5e721cc20d07193eee5d489077f4cb534f12c45f948e53247f79f38a5a7761f7`), pinned in
  `priv/affidavit/MANIFEST.json`; admission refuses a digest mismatch before compile, an import
  outside the four WASI imports the module declares, and a missing required export.
- `AshAffidavit.Refusal`: closed typed code set (host codes plus the engine's flat error codes read
  from the capability registry) with three distinct outcomes: `:refused`, `:trap`, `:unsupported`.
- Host files (`ABI`, `WasmConfig`, `EngineLoad`, `Host`, `Pool`, `mix ash_affidavit.vendor`,
  `mix ash_affidavit.verify`) are generated by the qri-consumer-binding-pack from a ConsumerBinding
  (`ontology/affidavit-binding.ttl` + `ontology/affidavit-contract.ttl`, profile beam-wasmex, authority
  ceiling NONE), pinned in `consumer-pack.pin` and regenerated with `scripts/consume.sh`
  (replaces `scripts/render_host.sh`). `priv/affidavit/MANIFEST.json` is generated by the same pack.
- Parity tests: regeneration equality against `consumer-pack.pin` digests (and live via
  `ASH_AFFIDAVIT_PACK_ROOT`), and authority NONE over all nine ops.
- No execution authority is granted by this package.
