## [v26.9.30](https://github.com/seanchatmangpt/ash_affidavit/releases/tag/v26.9.30) (2026-09-30)

Added surface (Ash extension and installer):

- `AshAffidavit.Resource` Spark extension: an `affidavit` section with a `runtime` entity
  (`wasm_path`, `timeout_ms`, `trusted_keys`, `server`, `singleton`) and `operation` entities.
  `Resource`, `Persist`, `Verify` and `Info` are generated from `ontology/affidavit-extension.ttl` by the
  ash-extension-pack (`scripts/render_extension.sh`, pinned by `ext_pack_*` in `consumer-pack.pin`);
  the legality checks (unknown op, bad ceiling, non-positive timeout, malformed trusted key,
  `singleton false` without `server`) live in `AshAffidavit.Resource.Validate`, the compiled shape in
  `AshAffidavit.Resource.Normalize`, and `AshAffidavit.Resource.Declared` reads `runtime/1` and
  `operations/1`. `AshAffidavit.Formatter`.
- `AshAffidavit.Reactor.Step`: one engine op as a Reactor step (only when Reactor is loadable).
- `AshAffidavit.call/2` returns `{:refused, %Refusal{code: :missing_field}}` for a non-object request
  (it raised `FunctionClauseError`), matching the node host.
- `AshAffidavit.call/2` refuses a response that states an authority above NONE
  (`:authority_escalation`, class `:refused_authority`); `AshAffidavit.authority_none?/1`.
- `scripts/consume.sh` refuses a pack export whose fingerprint differs from `pack_fingerprint`
  (`scripts/pack_fingerprint.py`); `reactor` and `igniter` are optional dependencies.
- `AshAffidavit.Change.Receipt`, `AshAffidavit.Validation.Verified`,
  `AshAffidavit.Calculation.Verdict`, `AshAffidavit.Type.Receipt`, `AshAffidavit.Type.ChainHash`,
  `AshAffidavit.Notifier`, `AshAffidavit.Error.Refused` (Splode wrapper of `AshAffidavit.Refusal`);
  telemetry `[:ash_affidavit, :op, :stop]`.
- `mix ash_affidavit.install [--target Module]` (Igniter, idempotent; manual steps without Igniter); the
  installer is generated by the ash-extension-pack (`Spark.Igniter.add_extension/5`; no local patch).
- CI, release and REUSE workflows; usage rules; `AGENTS.md`; documentation guides.

## 26.9.30

Initial release.

- `AshAffidavit.call/2`, `capabilities/1`, `abi_version/0`, `ops/0`, `registry/0` over the affidavit
  WASM engine (ABI 1, nine ops: `capabilities`, `commit`, `assemble`, `verify`, `mine`, `conform`,
  `verify_signature_input`, `certify_authzen_evidence`, `certify_spiffe_evidence`).
- Vendored engine `priv/affidavit/affidavit.wasm` (284650 bytes, sha256
  `5e721cc20d07193eee5d489077f4cb534f12c45f948e53247f79f38a5a7761f7`), pinned in
  `priv/affidavit/MANIFEST.json`; admission refuses a digest mismatch before compile, an import
  outside the four WASI imports the module declares, and a missing required export.
- `AshAffidavit.Refusal`: closed typed code set (host codes plus the engine's flat error codes read
  from the capability registry) with three distinct outcomes: `:refused`, `:trap`, `:unsupported`.
- Host files (`ABI`, `WasmConfig`, `EngineLoad`, `Host`, `Pool`, `mix ash_affidavit.vendor`,
  `mix ash_affidavit.verify`) are generated by the qri-consumer-binding-pack from a ConsumerBinding
  (`ontology/affidavit-binding.ttl` + `ontology/affidavit-contract.ttl`, profile beam-wasmex, authority
  ceiling NONE), pinned in `consumer-pack.pin` and regenerated with `scripts/consume.sh`
  (replaces `scripts/render_host.sh`). `priv/affidavit/MANIFEST.json` is generated by the same pack.
- Pack pinned at marketplace commit `20ff9279` (PR ggen-marketplace#557, base `80d429f1`), producer commit
  `16aa537f` (affidavit PR #112; engine wasm unchanged). `wasm_config.ex` gains `min_limit/1`; the ash-extension-pack
  moved to the same base and its installer defect is fixed upstream, so the local installer patch is removed.
- Parity tests: regeneration equality against `consumer-pack.pin` digests (and live via
  `ASH_AFFIDAVIT_PACK_ROOT`), and authority NONE over all nine ops.
- No execution authority is granted by this package.
